# Pedidos Compra

Aplicación web progresiva para la gestión de pedidos de compra.

## Comandos

- `npm start`: inicia el entorno local de desarrollo.
- `npm test`: ejecuta las pruebas.
- `npm run build`: genera la versión de producción en `build/`.

La instalación móvil utiliza `public/manifest.json` y
`public/service-worker.js`. La PWA debe publicarse mediante HTTPS (o ejecutarse
en `localhost`) para que el navegador pueda registrar el service worker.
